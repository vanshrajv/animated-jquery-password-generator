# 🔐 Animated jQuery Password Generator

A modern and fully animated **Password Generator** built using **HTML, CSS, and jQuery**. Generate secure random passwords instantly with customizable options and smooth animations.

## ✨ Features

* 🔐 Generate random secure passwords
* 🎚️ Adjustable password length
* 🔠 Include uppercase letters
* 🔡 Include lowercase letters
* 🔢 Include numbers
* 🔣 Include special characters
* 📋 One-click copy password
* 💪 Password strength indicator
* ✨ Smooth jQuery animations
* 🎨 Modern responsive UI
* ⚡ Fast and lightweight
* 📱 Mobile-friendly design

## 🛠️ Technologies Used

## 🎯 How It Works

The generator creates a password using the character types selected by the user.

Available character types:

```text
Lowercase → abcdefghijklmnopqrstuvwxyz
Uppercase → ABCDEFGHIJKLMNOPQRSTUVWXYZ
Numbers   → 0123456789
Symbols   → !@#$%^&*()
```

The password length can be customized using the length slider.
